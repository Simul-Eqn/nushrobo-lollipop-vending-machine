# NUSH Robotics Club's Lollipop Vending Machine

For Open House, when hosting exchange students, and potentially other events like CCA Fair, we will showcase our Lollipop Vending Machine. We must buy sufficiently many lollipops beforehand, and during the time period relevant, we should have someone manning the lollipop vending machine. 

`lollipop_machine.ev3` has the 2025 edition source code for the lollipop vending machine.
